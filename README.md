# Team 5C – Command Center Dashboard

Real-time analytics dashboard for monitoring Team 5B edge devices.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- MQTT
- WebSocket
- Leaflet
- Recharts
- Zustand
